# Sentiment-Analysis-on-speech
Real-Time Speech Emotion Recognition system using WavLM and NLP to classify emotions such as Happy, Sad, Angry, Fear, Neutral, Surprise, and Excitement from speech audio, with an API-based backend for emotion prediction.

This project focuses on detecting human emotions from speech audio using a combination of deep learning–based audio representations (WavLM) and sentiment analysis techniques. The system processes speech input, extracts meaningful audio features, and predicts emotional states such as Happy, Sad, Anger, Fear, Neutral, Surprise, and Excitement.

The solution is designed as a backend-driven application, where audio files are uploaded to a Python server, preprocessed, passed through a trained emotion recognition model, and the predicted sentiment is returned via an API response.
